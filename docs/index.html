trên 2 gói API Wealbee

Hai web cùng tính năng, cùng mã nguồn, chỉ khác gói API: một web dùng khoá gói Free, một web dùng khoá gói Doanh nghiệp, để so sánh trực tiếp. Số liệu BCTC từ Wealbee Data API; web bản Free dùng thêm API miễn phí của Vietstock (giá, tin). Tin tức từ app Wealbee. Hiệu suất API được quét tự động mỗi giờ.

Endpoint tin tức (JSON, cập nhật mỗi giờ): tin/moi.json · tin/ma/<MÃ>.json · vietstock/tin_moi.json · vietstock/tin_ma/<MÃ>.json
